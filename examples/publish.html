Advanced

Applied when the stream goes live, and at once while it is live.

import { WebRTCClient } from "@antmedia/webrtc-sdk"; const client = new WebRTCClient({ websocketURL, localVideo, }); // camera preview await client.media.initLocalStream(); // returned at once: listen first const session = client.publish( streamId, { token }); session.on("reconnected", () => console.log("live again")); await session.ready(); // live await session.changeBandwidth(1500); await session.stop();

The SDK calls behind this page. Its controls are small components given the same client and session.
